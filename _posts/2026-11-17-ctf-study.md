# CTF 문제 풀이 학습 기록

안녕하세요, ooxxd입니다!

이번에는 CTF 문제를 풀면서 배운 내용을 간단하게 정리해 보려고 합니다.

## 1. 학습 내용

웹 보안 문제를 해결할 때는 먼저 웹사이트의 구조와 요청 및 응답을 분석하는 것이 중요합니다.

이번 학습에서는 다음 내용을 살펴보았습니다.

- 웹사이트의 기본 구조 확인
- HTTP 요청과 응답 이해
- 개발자 도구를 활용한 분석
- 문제 해결 과정 기록

## 2. 느낀 점

아직 익숙하지 않은 부분도 많지만, 문제를 하나씩 해결하면서 원리를 이해하는 것이 중요하다고 느꼈습니다.

앞으로도 다양한 CTF 문제를 풀고 학습한 내용을 꾸준히 기록할 예정입니다.

## 3. 마무리

이번 글은 블로그 게시글 작성 및 카테고리 기능을 확인하기 위한 테스트 게시글입니다.
